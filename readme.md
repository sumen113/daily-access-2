## about

I have been using the same website for getting my school websites and links for the past 3 terms. But the problem? Both the UI and UX are horrible, that's why I have decided to make my own and put it through both an extension and a userscript executor.

But how does it work? My userscript simply just deletes the whole page and adds its own, think of it like this, you have an essay( with really bad hand writing ) and then erase the whole thing before writing a better essay.

## download or install

Download:

To download this it basically means to use a user script manager, for example: [taper monkey](https://www.tampermonkey.net/), [violent monkey](https://violentmonkey.github.io/), or [fire monkey](https://github.com/erosman/firemonkey), you could use a [tutorial](https://youtu.be/zGn0wA9n4mc?si=IBq9Yb958yjZmxIv) if this is your first time. With a user script manager fully installed, you can upload my [script](https://greasyfork.org/en/scripts/605427-daily-access-2-demo)( demo version for testers ) to it and once that is installed as well, you can test it [here](https://da.gihs.sa.edu.au)

Install:

This way is done through extensions, I have supported two browser types for this project, chromium and firefox. Now to get these extensions on your device you will need to download the extension [files](https://github.com/sumen113/daily-access-2/releases/tag/extensions), for chrome you will need to extract the zip. With this file you will go to extension page, for firefox enter this: "about:debugging#/runtime/this-firefox" and for chrome enter this: "chrome://extensions". on this page you will have to load the file, for firefox click the "load temporary addon button" and for chrome, make sure to enable the developer mode first before clicking load unpacked. Once it is fully installed as, you can test it [here](https://da.gihs.sa.edu.au)

## how to use

My enhancement simply replaces the [daily access](https://da.gihs.sa.edu.au) page at my school, making not much of change in functionality, but the few changes include 1: saving of login(only applies to the non-demo version), 2: Addition of choosing which website you want for the daily access and 3: customisation of themes. There is no true guide to use as it simply is really self explanitory(click website, go link).

## make your own

This project may seem really made just for my school, it could easily be applied to whatever daily access your school may have. The process goes as follows, make sure to clone my repo, probably just the draft, change up 1: the names and logo, and 2: the links, this is before turning that change of code into either an extension, userscript or in my case, both.
